Pseudo Elements

Pseudo-elements style a part of an element or add content: ::before, ::after, ::first-letter, ::first-line, ::selection and ::placeholder.

CSS lets you control the look of a page. With a few lines you can change colors, spacing and layout, and one stylesheet can be reused across every page of a website. Pseudo-elements let you target the first letter or the first line of a paragraph.
