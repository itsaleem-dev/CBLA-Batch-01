Responsive Typography

Responsive typography: fluid sizes with clamp(), a readable line length with ch, and a media query refinement.

Typography that adapts

Text should be comfortable to read on every screen, from a phone to a wide monitor.

CSS lets you control the look of a page. With a few lines you can change colors, spacing and layout, and one stylesheet can be reused across every page of a website. A good line length is around 45 to 75 characters, which is why this article is limited to 65ch.

Fluid headings

The headings grow smoothly with the viewport width. Resize the window to see the sizes change without sudden jumps.
